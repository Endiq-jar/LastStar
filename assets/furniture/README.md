# KayKit Furniture Bits

The bed, couch, table, chair, shelf, rug and shared texture are from Kay Lousberg's [KayKit Furniture Bits](https://github.com/KayKit-Game-Assets/KayKit-Furniture-Bits-1.0), CC0 1.0. Source: commit `96d5930a8dbdb363409bbc2d3341718b00e17c9c`, `addons/kaykit_furniture_bits/Assets/gltf/`. Used unmodified.

The four `_Mid.glb` variants are simplified from the CC0 source models with
glTF Transform 4.2.1 (`weld`, then `simplify --ratio 0.5 --error 0.02`).
The original furniture remains the near-distance model. These derivatives retain
the source material/texture and are used at 15–50 m before distance hiding.
