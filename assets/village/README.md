# Medieval Village MegaKit (Standard)

Seven models from Quaternius' Medieval Village MegaKit Standard, CC0 1.0:
https://store.godotengine.org/asset/quaternius/medieval-village-megakit/
https://quaternius.com/packs/medievalvillagemegakit.html

Retrieved from a public mirror of the Standard pack:
https://github.com/Barbatos6669/elderforge/tree/bb2ce469f0ab2ccfc487faef55550ba07fae2483/assets/Medieval%20Village%20MegaKit%5BStandard%5D/glTF

Changes: glTF materials retain base color only (normal and roughness maps
removed for performance), and base-color textures were resized to 512 px and
converted to JPEG. Geometry/buffer data is unchanged. This is only a small
subset of the free Standard pack, not the paid Pro or Source pack.
CC0: https://creativecommons.org/publicdomain/zero/1.0/
